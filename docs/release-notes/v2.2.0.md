## Airwave Spatial Audio Unit

Airwave now includes a stereo spatial audio effect for macOS hosts that support AUv3. Add **Airwave Spatial** to a track or output effects chain to use Airwave's headphone spatialization with the audio your host is already mixing.

- Start with **Neutral** or import a compatible HeSuVi WAV from the **HRIR preset** menu.
- Use **Bypass** to compare the original stereo signal with the spatialized output.
- The host can save the imported WAV and bypass setting with each plugin instance.

Install Airwave in Applications and open it once. Then rescan Audio Units or restart your host if it was already running. You can quit the Airwave app while using the plugin. Use your host's effects chain for EQ.

See [Airwave Spatial setup](https://github.com/sallliisa/Airwave#airwave-spatial-audio-unit) for details.
