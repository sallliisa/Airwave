## Expanded Equalizer APO support

- Import `GraphicEQ` curves and more parametric filters, including pass, notch, all-pass, shelf, and custom IIR filters.
- Import a folder containing `config.txt` to keep included configs and WAV impulse responses together. Airwave copies the files it needs into its preset library.
- Use channel selection, channel copying and mixing, delay, and WAV convolution on stereo playback.
- Use device and sample-rate conditions to apply different settings as you switch audio outputs.

## Import fixes

- Select config folders directly in the import picker. If you select a config file that needs access to companion files, Airwave lets you choose its folder from the import dialog.
- Import errors use Airwave’s standard dialogs and show the source file and line when available.

Go to **Settings → Equalizer → Import…** to add a preset. Select a `.txt` file for a standalone preset or the folder containing `config.txt` for a multi-file preset. Convolution WAVs must match the output sample rate.
